# API

> Examples assume the default `BASE_PATH=/app`; substitute your own `BASE_PATH` if you have changed it.

This document describes the API surface implemented in the current codebase.

At runtime the server mounts the API under `/app/api`. Route tables below omit the `/app` deployment prefix and use `/api/...` for readability.

## Response Shape

Most JSON endpoints return:

```json
{
  "success": true,
  "data": {}
}
```

Paginated endpoints add `meta`:

```json
{
  "success": true,
  "data": [],
  "meta": {
    "total": 0,
    "page": 1,
    "limit": 20
  }
}
```

Errors use the shared error handler:

```json
{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "Resource not found"
  }
}
```

## Access Levels

| Level | Meaning |
|---|---|
| Public | No session required. |
| Authenticated | Requires a valid session cookie. |
| Admin | Requires a valid session and `user.role === "admin"`. |
| Setup | Available before the encrypted database is unlocked. |

All full-app protected routes pass through `requireUnlocked` before module route handlers run.

## System and Setup

| Method | Path | Access | Description |
|---|---|---|---|
| GET | `/api/health` | Public | Liveness probe. Returns `{status: "ok"\|"locked"}` (HTTP 200 either way; orchestrators should consult `/encryption/status` for richer state). |
| GET | `/api/encryption/status` | Public | Encryption initialization and lock state. Trimmed payload — no kdfSalt / encryptedDek / challenge. |
| POST | `/api/encryption/unlock-challenge` | Public (locked-only, per-IP rate-limited) | Returns `{challenge, encryptedDek, kdfSalt}` — the bundle the SPA needs to perform an unlock attempt. |
| POST | `/api/encryption/init` | Public (uninitialized-only, bootstrap-token gated) | First-time encrypted database initialization. |
| POST | `/api/encryption/unlock` | Public (locked-only, per-IP rate-limited) | Unlocks the encrypted database. |
| GET | `/api/docs` | Admin (unlocked-only) | Scalar API reference UI. |
| GET | `/api/openapi.json` | Admin (unlocked-only) | OpenAPI document generated by `OpenAPIHono`. |
